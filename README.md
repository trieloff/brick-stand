# brick-stand

Tenting stand for the [ZSA Voyager](https://www.zsa.io/voyager) split keyboard, designed parametrically with [ForgeCAD](https://github.com/KoStard/ForgeCAD).

## Reference geometry

`reference/` contains STL files used as design references — not part of the printable stand:

- `bottom_plate_left.STL` / `bottom_plate_right.STL` — official ZSA Voyager bottom shells (from <https://www.zsa.io/assets/voyager/voyager_stl.zip>)
- `ZSA Voyager Tripod Mount.stl` — [mark's tripod mount](https://www.printables.com/model/607727-zsa-voyager-tripod-mount), reference for the magnet + guide-pin mating pattern
